# RoCo Works Site

Static GitHub Pages site for RoCo Works at `https://rocoworks.com`.

## Privacy Policy URL

The Steady App Store privacy policy lives at:

`https://rocoworks.com/steady/privacy/`

Edit `steady/privacy/index.html` to update the policy text, effective date, or
support email. The current contact address is `support@madebyroco.com`.

## Deploying

This site is plain static HTML and CSS. GitHub Pages can serve it directly from
the repository root:

1. Push changes to the branch configured for GitHub Pages.
2. In the repository settings, set GitHub Pages to deploy from the branch root.
3. Keep the `CNAME` file in place for the custom domain `rocoworks.com`.

No build step or package installation is required.
